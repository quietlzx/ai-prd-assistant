# AI PRD Assistant

AI PRD Assistant is a Codex Skill that converts raw product requirements into a
structured, reviewable PRD package.

It provides:

- a fixed serial workflow
- structured stage artifacts
- `READY`, `DRAFT_WITH_GAPS`, and `BLOCKED` Gate decisions
- six-category AI risk analysis
- a human-review control gate
- Markdown and self-contained HTML report assembly
- a deterministic structure-only Harness

See `README.md` for the full English usage notes and repository layout.
